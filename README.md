# Kalkulator JavaFX

Aplikasi kalkulator sederhana dengan tampilan GUI seperti kalkulator di HP, dibuat dengan JavaFX di Apache NetBeans.

Bisa untuk tambah, kurang, kali, dan bagi, serta tombol `C`, `±`, `%`, dan desimal.

## Cara Menjalankan

1. Buka project di NetBeans (**File → Open Project**).
2. Klik kanan project, pilih **Clean and Build**.
3. Klik kanan project, pilih **Run**.
